# SILENT DEPTH

ブラウザで遊ぶ、潜水艦同士／潜水艦 vs 駆逐艦のリアルタイム戦術ゲーム。`plan.md` をもとに、1人用の敵AI対戦として実装しています。音響の聞き分けは不要で、システムが信号強度・方位・推定艦種・信頼度を提示します。

## 起動

Docker Desktop（またはDocker EngineとDocker Compose）がある環境で、プロジェクトのディレクトリから実行します。Node.js、Python、追加パッケージのインストールは不要です。

```sh
docker compose up --build
```

ブラウザで **http://localhost/game/submarine** を開いてください（`/game/submarine/` が正規URLです）。終了はターミナルで `Ctrl+C`。バックグラウンドで起動する場合は `docker compose up --build -d`、停止は `docker compose down` を使います。JSONを読み込むため、`index.html` の直接オープンには対応していません。実行時に外部サービスや追加パッケージは不要です。効果音はブラウザ内で生成し、日本語報告の音声ファイルを同梱しています。

## 士官チームの自動運用を観戦

出撃画面でシナリオを選び、**「潜水艦の模範運用を観戦」** を押すと、潜水艦を選んで全自動・4倍速で出撃します。「自由演習」では「指揮モード」で自動運用を選べば、駆逐艦でも観戦できます。

- ソナー員：接触・被探知の根拠・測距の不確実さを報告。
- 砲雷長：兵装、残弾、再装填、攻撃深度、デコイを確認。
- 機関長：指示速力・深度を艦の性能と海底余裕の範囲に調整。
- 航海長：接近・観測・離脱・回避の進路を確認。
- 艦長：報告を統合し、約2秒のゲーム時間ごとに判断して実行。

「士官チーム・指揮所」で現在の判断と各部署の報告を確認できます。「艦長の判断記録」には、実行時の理由と内容が残ります。任務終了後は **「戦術・指揮記録を見る」** で記録を振り返れます。ソナーには自艦の航跡も表示します。航跡・報告はプレイヤーが観測できる情報だけを使います。

観戦中はガイドの自動停止と個別の手動操艦・発射を無効にします。一時停止・再開・倍率変更・操作ガイドは利用できます。 **「自分で操艦を引き継ぐ」** で自動指揮を解除し、1倍速・一時停止で引き継ぎます。 **「艦長に任せて観戦する」** で再委任できます。タブ非表示時にも停止します。

これは既存の隠密接近アドバイザーを使った、現在のゲーム内での模範運用です。敵の隠れた状態を参照せず、命中や勝利を保証しません。現実の潜水艦運用の再現や、あらゆる状況で最適なAIではありません。

## シナリオ

出撃画面で以下の6本を選べます。お手本5本は212A型潜水艦専用の架空任務です。自動観戦・提案の承認・手動操作のいずれでも遊べます。

| シナリオ | 学ぶ行動 | 成功条件・制限時間 |
| --- | --- | --- |
| お手本01 — 静かな接近 | 低速で接近・観測し、必要な測距を行い、攻撃後に離脱 | 敵艦撃破・25分。未発見の維持は必須ではありません |
| お手本02 — 待つ勇気 | 最初の90秒は静止観測し、近づく敵を待って攻撃 | 敵艦撃破・25分 |
| お手本03 — 追跡を振り切れ | 発見済みの状態から、デコイ・回避を使って指定区域へ航行 | 生存して離脱区域に到達・15分。敵撃破だけでは成功しません |
| お手本04 — 深海の対決 | 潜水艦同士で索敵し、測定した敵深度に魚雷を発射、反撃を回避 | 敵潜水艦撃破・25分 |
| お手本05 — 撃たずに帰れ | 攻撃禁止で敵潜水艦の魚雷を回避し、終盤は減速して離脱 | 離脱区域へ生還・15分。敵の接触喪失は判定しません |
| 自由演習（従来の任務） | 潜水艦・駆逐艦を選んで対戦 | 敵艦撃破・25分 |

任務目標欄には待ち伏せの残り時間や離脱区域までの距離を表示します。離脱区域はソナーにも表示します。待ち伏せ中も兵装接近や海底接触の危険には優先して対応します。

## 初めて遊ぶ場合

出撃画面の **「ガイド付きで出撃する」** をONにしてください。初期状態はONです。

1. 画面上部の **戦術アドバイザー** に、次の行動・理由・実行内容が表示されます。
2. 探知・測距・攻撃と、初回の回避判断ではゲームが一時停止します。ゆっくり説明を読めます。
3. **「提案を承認して実行」** を押すと、その提案だけを実行して時間を再開します。発射時は兵装・深度・消費弾数を確認できます。
4. **「自分で操作する・進行を再開」** で手動操作もできます。 **「操作場所を見る」** は対応する操作欄へ移動して強調表示します。
5. 慣れたら **「学習の節目で一時停止」** をOFFにしてください。提案表示はそのまま利用できます。ガイド設定はブラウザに保存されます。

手動での探知・測距・発射も学習の進捗に反映します。ガイドは通常の任務を案内するもので、無敵の練習モードではありません。承認後に時間が進むと敵AIも行動します。

提案には、減速して索敵、ピンによる測距、兵装選択と攻撃深度、接近、観測待ち、デコイと回避、海底接触回避が含まれます。接近警報は攻撃より優先します。アドバイザーは敵の真の位置や健全性を参照せず、プレイヤーと同じ観測情報を使います。提案時から戦況が変わった場合は再確認を求めます。操艦・兵装は承認なしでは実行しません。

## ソナー員と隠密接近

戦術アドバイザーに、ソナー員の状況報告と方針選択を追加しています。

- 被探知状況は「不明」「自艦方位を暴露」「敵が能動捜索中」「接近兵装を探知」などとして、観測根拠とともに表示します。敵のピンの傍受だけでは自艦が発見されたと断定しません。
- 測距できた場合は推定距離・誤差・魚雷の直進到達時間を表示します。距離未確定時には数値を捏造しません。
- 潜水艦は6 ktでの隠密接近と観測を基本とし、おおむね2 km前後で攻撃を提案します。距離が推定できないまま観測が続いた場合は、リスクを説明してピンによる確認を提案します。
- **接近を続ける／ここで攻撃する／静かに離脱する／ピンで確認**から選択できます。選択時に一時停止し、内容を確認して承認すると実行します。新しい測距情報や弾薬がない場合は、攻撃できない理由を表示します。
- 攻撃後は40秒を目安に低速で離脱。接近警報があれば、通常の選択肢を外してデコイと高速回避を優先します。
- 駆逐艦は能動捜索を基本とする既存の方針を維持します。

報告・提案はゲーム内の簡易モデルに基づきます。2 kmは安全を保証する距離ではなく、敵の隠れた位置や探知状態を参照した命中率・発見確率は表示しません。

## 遊び方

1. シナリオを選び、目標を確認して出撃します。自由演習では**212A型潜水艦**または**フレッチャー級駆逐艦**を選択できます。
2. 低速で受動索敵。ソナー上の破線は「方位」で、敵の距離を示していません。
3. 潜水艦は低速で接近・観測し、必要に応じて**アクティブ・ピン**で距離と深度を取得します。駆逐艦はピンによる積極的な測距が基本です。敵にも自艦方位が伝わります。範囲外や水温躍層の影響で反響が得られない場合があります。
4. 兵装を選び、攻撃深度を合わせて発射。潜水艦で水上艦を狙う場合は0 m、駆逐艦で潜水艦を狙う場合は測距した深度が目安です。
5. 敵兵装の接近警告が出たら、デコイと回避機動を併用します。デコイには残数と再装填時間があります。
6. 制限時間内に任務目標を達成すれば成功。離脱任務では攻撃より指定区域への到達を優先します。自艦の船体健全性が0、または目標未達で時間切れになると失敗します。

`P`：ピン、`D`：デコイ、`Space`：一時停止／再開。入力欄やボタンを操作中はショートカットを抑制します。時間倍率は1・2・4・8倍。タブが非表示になると自動停止します。操作ガイドを開いている間も停止します。

### 索敵と環境

- 受動ソナーのS/Nは発生雑音・距離損失・自己雑音・ソナー性能・水温躍層から算出します。
- アクティブソナーの位置は**最後に測距した位置**です。敵の移動に追従せず、誤差円が広がり、65秒で失効します。
- TMAは18°以上の変針、7回以上の観測、150 m以上の移動などを条件に、観測した方位線の交差から距離を概算します。敵の真の座標は参照しません。移動する敵に対して誤差が出る簡易モデルです。
- 高速・浅深度でキャビテーションが発生。減速・深度変更で発生を抑えられます。
- 海流による偏流、場所ごとの海底深度、海底接触による損傷を実装しています。海底近くで停止すると音響的な隠蔽効果が得られます。
- 魚雷は近距離で追尾を始めます。有線誘導魚雷は更新された測距位置を利用します。爆雷は自艦位置から沈降し、ヘッジホッグは艦首方向の測距位置に投射します。ロケット魚雷は測距位置に着水して追尾を開始します。

## 音声・効果音

出撃ボタンを押すと音声が始まります。右上の「音声」から音量、全体ミュート、日本語報告のON/OFFを設定できます。設定はブラウザに保存されます。「音声テスト」は出撃中に利用できます。

- ピン、反響・接触通知、敵ピン、兵装発射、デコイ、爆発、被弾警報、任務終了の効果音。航行中は小さな機関の環境音も再生します。
- 日本語のシステム音声を利用できる場合、ソナー員が観測した方位・距離・深度を読み上げます。声によってはOS／ブラウザ側でネットワーク接続が必要です。
- 日本語音声がない、または読み上げに失敗する環境では、同梱した27種類の日本語報告を再生します。同梱音声は短い定型報告で、具体的な数値は画面で確認できます。
- 魚雷接近・被弾・任務終了の報告を優先。倍速でも報告を溜めず、古い報告を破棄します。
- ミュート、一時停止、操作ガイド、タブ非表示、再出撃では音声も停止します。ミュート中の報告を後から読み上げることはありません。ガイドによる自動停止時だけは、その判断に関する報告と効果音を最後まで再生します（航行環境音は停止）。

同梱音声はOpen JTalkで生成しました。出典とライセンスは [`assets/voice/ATTRIBUTION.md`](assets/voice/ATTRIBUTION.md)、台本は `assets/voice/reports.json` にあります。生成ツールを使う場合だけOpen JTalk・辞書・音声モデルを別途用意してください。

### シナリオを増やす

1. `scenarios/stealth.json`などをコピーし、`scenarios/my-mission.json`を作ります。
2. `id`を重複しない値に変え、`title`・`briefing`・`lessons`・`objective`を編集します。
3. `overrides`に初期配置・海流・制限時間・敵AIなど、`scenario.json`から変更したい項目だけを書きます。省略した項目は共通設定を継承します。
4. `scenarios/index.json`の`scenarios`配列に`{ "id": "my-mission", "file": "my-mission.json" }`を追加してブラウザを再読み込みします。

`objective.type`は`DESTROY`（敵艦撃破）または`ESCAPE`（区域への到達）です。離脱の場合は`scenarios/escape.json`を参考に`objective.zone`へ中心座標`x`・`y`と正の`radius`をメートル単位で指定してください。区域全体が作戦海域内に収まる必要があります。

`playerShip: "type_212a"`で潜水艦専用にできます。省略すると艦種を選択できます。`enemyShip: "type_212a"`で敵を潜水艦に指定できます。省略時は従来どおり自艦と異なる艦種が選ばれます。「深海の対決」は双方に212A型の性能・装備を使い、弾薬や損傷は独立して管理します。`policy`を省略すると通常の接近・攻撃方針です。待ち伏せは`{ "mode": "AMBUSH", "holdSeconds": 90 }`、離脱任務は`{ "mode": "ESCAPE" }`を指定します。発見済みで開始する場合は`overrides.initialDetection`を`true`にします。新しい種類の目標や指揮行動を追加する場合は、ゲーム本体やアドバイザーの実装も必要です。

## 3D戦術ビューと測量士

ソナーに加え、海図・測深・接触情報から海中を立体的に再構成します。自艦の旋回・深度、海底、水温躍層、航跡、接触の推定範囲を表示します。回転・拡大・躍層の表示切替が可能です。深度方向は4倍、艦体は見やすい大きさに強調しています。ブラウザのCanvasで3D座標を投影し、追加ライブラリや外部配信サービスは使用しません。

出撃画面の「海図の充実度」から選びます。任務の目標・敵の性能は変わりません。

- **既知海域**：海図の概算地形を最初から表示（深度誤差の目安 ±40 m）。
- **部分調査**：東側の x > 800 m に未測量区画が残ります。
- **未調査海域**：直下の記録から開始し、航行と周辺走査で地図を作ります。

測量士は既存の直下水深計の情報を約1秒ごとに記録します（400 m区画、誤差の目安 ±25 m）。その記録だけで遠方の海底は判明しません。「周辺走査・ピン発信」または通常のアクティブ・ピンで、半径1.8 kmの海底を更新します（±10 m）。これはゲーム用の簡易測量モデルです。走査は索敵用ピンと同じ発信・再充填を使い、敵に自艦方位を知らせます。測量士は独断で発信しません。自動運用中は艦長の判断によるピンで地図が更新されます。

青い海底は海図、緑のメッシュは走査済み、点は航行中の直下記録、空白は未測量です。取得した情報はその任務中に蓄積し、再出撃でリセットします。既知率・測深済率は**現在の自艦周辺1.8 km**の割合なので、航行して対象範囲が変わると下がることがあります。

測量士は指示針路の前方1.2 kmについて未測量区画や海底余裕を報告します。既知の浅海に対しては海図の誤差を考慮し、アドバイザーが減速・浮上を提案します。自動運用では艦長がこの提案を実行します。未知の地形を先読みした航路計算や、地形による音響遮蔽は行いません。

### 戦闘演出と情報の制限

魚雷などの発射、デコイの音響波、接近方位、旋回・潜航、被弾の衝撃、命中推定・回避成功の通知を3Dビューに表示します。発射直後の航跡は短い模式演出です。兵装の実際の追尾軌道・敵の未観測位置・爆発の正確な座標は戦闘中の表示へ渡しません。受動接触は方位の帯、測距済みの接触は時間とともに広がる誤差範囲で表し、深度不明の接触はその旨を表示します。

演出はゲーム内時間に従い、一時停止中は停止します。倍速時も同じ倍率で進みます。「演出を抑える」で波紋・発射演出の動きを抑制でき、OSの動きを減らす設定を初期値に反映します。

### 任務後の3D戦闘リプレイ

任務終了画面の「3D戦闘リプレイを見る」、または任務目標欄の「3D戦闘リプレイ」で開きます。約1秒間隔の記録を再生し、スライダーで見たい場面へ移動できます。敵艦・両軍の魚雷・デコイ・爆発位置は、ここで初めて実際の位置を公開します。再生は約4倍速です。リプレイの海底は任務後の海図再構成で、戦闘中に取得した範囲の再現ではありません。

記録はその出撃のメモリ内だけに保存し、再出撃・再読み込みで消去します。動画の保存、フレーム間の補間、音声の再演は行いません。

実装は `src/survey.js`（海底の既知情報と測量士）、`src/tactical.js`（立体描画）、`src/game.js`（観測用イベントと終了後リプレイ）に分離しています。`tests/survey.test.js` で未知地形の非参照、走査の露見・再充填、精度・蓄積・リセット、浅海への対応、戦闘中の非公開情報、終了後だけのリプレイ公開を検証します。
